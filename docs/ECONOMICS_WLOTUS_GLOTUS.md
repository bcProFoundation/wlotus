# Economics — wLotus + Golden Lotus

**Status:** design update (2026-08-04) — issuer tax reduced from **107** to **6** per remint.  
Related: [VISION.md](./VISION.md) · [ECONOMICS.md](./ECONOMICS.md) · [CLOCK.md](./CLOCK.md)

## Thesis

| Token | Ticker | Role | Monetary? | Mint posture |
|-------|--------|------|-----------|--------------|
| **wLotus** | `WLOTUS` (test: `dWLOTUS`) | Memorial / dana proof | **No** (ceremonial) | Small temple tax; mobile may get **sponsored XEC fees** |
| **Golden Lotus** | `GLOTUS` | Scarce burnable value for special events & later commerce | **Yes** (real cost) | **Permissionless** remint; miner pays own XEC; **no platform mint tax** |

People **offer for wLotus**. wLotus is generated by PoW remint. **GLOTUS** is the economic layer (premine + open mining + event burns).

```
Offer (mobile, temple-sponsored fees)
        │
        ▼
   Mint 7 wLotus
        ├── 1  → miner / offerer
        └── 6  → temple (wlotus.org)  — fee reimbursement & desk inventory

Burn / give wLotus          ← scalable path for non-miners (transfer then offer)
Mine GLOTUS                 ← open, miner pays XEC; burn on special events
```

## wLotus

### Issuance split (covenant-enforced)

Each successful remint mints **7** atoms:

| Share | Destination | Purpose |
|------:|-------------|---------|
| **1** | Miner / offerer | Presence bead — kept or later burned/given |
| **6** | Temple **P2SH** (IFP-style multisig / cold) | Issuer tax — fee reimbursement & inventory |

Anyone may satisfy the covenant (including copied clients) **if they pay their own XEC fees** and accept the **6→temple / 1→miner** outputs (temple keeps **≈86%** of each mint).

**Launch custody:** temple sink is **P2SH**. Redeem is revealed only on spend. See [Temple custody](#temple-custody).

### Why 6 (not 107)

Earlier design used **108** (one mala: 1 presence + 107 temple) as a strong anti-farm tax against independent fee-paying miners. Launch now starts at **baseZeroBits = 0**, so mobile users and professional hashrate already share a soft PoW field; the heavy 107 tax is no longer the primary equalizer.

Reducing the issuer tax to **6**:

- Leaves independent miners a meaningful fraction (**1/7 ≈ 14%** vs **1/108 ≈ 0.9%**).
- Opens the token economics to third-party clients and developers.
- Still funds the desk for sponsored mobile offerings and inventory distribution.

Presence / anti-farm levers that remain:

| Mechanism | Role |
|-----------|------|
| **1 miner / 6 temple** | Modest covenant tax; desk still majority share |
| **Soft pray timer** (`VITE_MIN_PRAY_SECONDS`) | Attention tax after remint |
| **PoW bits (base 0, whole-byte)** | Soft launch; headroom to 128 sunset |
| **Moore clock (+1 bit / 500 days)** | Intentional dearening over years |
| **128-bit hard sunset** | Covenant `verify bits <= 128` |
| **Desk tips at launch** | Serve **1** tip first |
| **Pagoda burn → remint loop** | Memorial burns recirculate demand |

**Do not claim:** “more WLOTUS hashrate = safer token.”  
**Do claim:** sponsored Offer can still win on **XEC cost**; sincere users pay **attention**; non-miners **buy / receive / burn**.

### Independent miners vs desk (XEC cost)

Reference fee: **~5.46 XEC** per remint. Burn-after-mint adds a second fee → **~11 XEC** desk cost per sponsored remint that leaves **6** temple inventory atoms.

| Actor | XEC out | wLotus kept | Implied cost / lotus |
|-------|--------:|------------:|---------------------:|
| **Temple desk** (sponsor remint + burn) | ~11 | **6** inventory | **~1.8 XEC** (`11 / 6`) |
| **Independent miner** (pays own remint; keeps the 1) | ≥ ~5.46 | **1** | **≥ ~5.46 XEC** |

Desk still has a better cost basis than a pure fee-paying solo miner, but the gap is narrower than under 1/107 — intentional so third-party mining is not uneconomic by design alone.

### Soft timer (attention), not hashrate security

Phone electricity ≪ XEC fee. Ritual value is **minutes of presence**, not SHA256d network work.

- Official Offer: device PoW → **remint immediately** → soft pray floor → **memorial burn**.
- Cancel during the soft wait **skips the burn**; the miner atom stays with the desk.
- Soft timer must **not** delay remint — that would lose tip races.

### Non-miners and scale

1. Temple (or others) **transfer** wLotus to someone who will not mine.
2. Recipient **offers / burns** on-platform.

Burning/giving is the scalable ritual; mining is issuance + presence tax.

### Mobile fee policy (off-chain)

| Who | XEC remint fee |
|-----|----------------|
| Official mobile / mint-api | Temple may **sponsor** (rate-limited) |
| Anyone else | Pays own XEC; still must mint **6→temple, 1→self** |

### Convertibility

wLotus ↔ GLOTUS **may** exist later at a **very large** fixed ratio. Prefer **defer** at launch (avoids a shadow price on ceremonial wLotus).

## Golden Lotus (`GLOTUS`)

### Role

- Higher economic weight than wLotus.
- Burned on **special events** (real sacrifice / ticket-like cost).
- Suitable later as a commerce unit **because mint is not temple-taxed**.

### Premine

An initial **premine** (disclosed %) funds development, marketing, and onboarding. Publish allocation + vesting.

### Mint policy

| Option | Verdict |
|--------|---------|
| Platform cut on every GLOTUS mint | **Reject** for launch |
| Permissionless mint; miner pays XEC only | **Adopt** |
| Temple revenue | Premine + event burns + optional *services* priced in GLOTUS |

### Openness

GLOTUS mining is **permissionless**. No requirement to pay wLotus or route mint outputs to the temple.

| Story | Memorial, dana | Scarce golden offering / event value |

2. Premine % and vesting for GLOTUS.
3. Fee policy (who gets sponsored XEC).
4. Explicit: wLotus is ceremonial; GLOTUS is the economic token.

## Temple custody

**Covenant destination: temple P2SH** (`templeScriptHash` — 6 atoms per remint).

| Layer | Address type | Role |
|-------|--------------|------|
| Temple (in covenant) | **P2SH** (multisig / cold) | Receives 6/remint |
| Spends | Redeem + keys | Rare treasury moves |

**Dryrun convenience:** if `TEMPLE_ADDRESS` is unset and ticker is not `WLOTUS`, `create-wlotus-token` P2SH-wraps the genesis wallet’s P2PKH. Launch / ticker `WLOTUS` must set `TEMPLE_ADDRESS` to a real multisig P2SH.

```bash
TICKER=dWLOTUS TEMPLE_ADDRESS=ecash:p… BATONS=28 npm run create-wlotus-token
TEMPLE_ADDRESS=ecash:p… BATONS=28 npm run create-wlotus-token
```

## Implementation notes

- Covenant: `WlotusPowRemintMooreTipTemple` — mint **7**; **1** miner P2PKH + **6** temple P2SH.
- **Memorial:** burn the miner **1** after remint (`DANA` LOKAD on burn tx).
- Genesis: `baseZeroBits = 0`, Moore **500 d**/bit. Only `TICKER` differs (`dWLOTUS` vs `WLOTUS`).
- Mint-api / web: temple remint → burn miner atom; `memorialOnBurn: true`. Soft tip count `MINT_SERVING_TIP_COUNT=1` at launch.
- Soft pray: `VITE_MIN_PRAY_SECONDS` on the Offer client.
- GLOTUS: separate token; open remint; no temple mint tax.

**Immutability:** changing the split requires a **new genesis**. Existing on-chain WLOTUS/dWLOTUS covenants cannot be rewritten.

Settled intent: light issuer tax = **1/6**; presence = **soft timer + base 0 Moore ramp**.
